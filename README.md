# SEO Tools & Workflows

A curated suite of custom-built, TypeScript-driven applications designed to automate technical audits, content optimization, template extraction, and structured data generation.

---

### Included Tools

* **[audit-js-heavy-websites](audit-js-heavy-websites)**
  Analyzes client-side rendered (CSR) and JavaScript-heavy pages to uncover rendering bottlenecks, hydration issues, and missing DOM elements impacting crawlability and indexation.

* **[aura-content-orchestrator](aura-content-orchestrator)**
  Automates end-to-end SEO content workflows, keyword intent grouping, and page-level optimization pipelines.

* **[page-template-identifier](page-template-identifier)**
  Classifies, segments, and groups URLs across large sites into distinct page templates to streamline enterprise-level technical audits and diagnostics.

* **[schema-architect](schema-architect)**
  AI-powered JSON-LD structured data generator and validator tailored for Schema.org standards, Google rich results, and Answer Engine Optimization (AEO).

---

### Tech Stack

* **Core:** TypeScript, React, Vite, Tailwind CSS
* **Integrations:** Google Gemini API (`@google/genai`)
